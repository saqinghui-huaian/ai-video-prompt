# 主体系 · 抽象情绪改写表（质检第 17 条执行工具）

> 规则：段 4 不得出现抽象情绪词，一律改写为 **光位 / 材质 / 动作 / 物件 / 声音** 五个通道之一。质检第 17 条即查此项。
> 定位：质检工具，不改五段结构；本表只提供改写路径，不新增槽位。
> 分组逻辑：按**这股情绪从哪儿来**分四类。理由是不同的来源要用不同的通道去接——关系类的情绪藏在距离里，受压类的藏在呼吸里，内转类的藏在停顿里，欲望类的藏在物件里。查表时先判断来源，改写方向就定了。
> 规模：4 组 25 词。

## 一、五通道改写法（先掌握这个，再查表）

情绪不能直接写，但可以落在五个地方。改不出来时挨个问一遍：

| 通道 | 问自己 | 例子 |
|---|---|---|
| 光位 | 光在他身上怎么落的 | `顶灯只照到半张脸，另一侧留在暗里` |
| 材质 | 什么表面正在变化 | `掌心的汗把纸角洇软` |
| 动作 | 身体哪个部位先动 | `喉结动了一下` |
| 物件 | 什么东西替他说了话 | `被指节压出白痕的纸杯` |
| 声音 | 什么声音暴露了状态 | `呼吸声压在环境声之下` |

**判断改写是否成立的标准**：能在画面里看见，或能在声音里听见。两样都占不到，就是没改写，只是换了组词。

## 二、A 组 · 关系变化（7 词）

**这股情绪从哪儿来**：另一个人在场，情绪由对方的动作或存在引发。
**通用切入口——看距离**：谁离谁更近了、谁的视线落在对方身上、谁把身体转向了别处。关系的变化先出现在空间关系上，后出现在脸上。

| 情绪 | 不要这样写 | 改成这样 |
|---|---|---|
| 孤独 | 她很孤独 | 双人床只铺了一侧，另一侧的枕头压痕早已平了 |
| 释然 | 他终于释然 | 肩膀落下去半寸，攥着的那只手松开 |
| 温柔 | 温柔地看着他 | 动作放慢，替对方把袖口理平 |
| 冷漠 | 表情冷漠 | 目光没离开屏幕，回话只有一个音节 |
| 傲慢 | 态度傲慢 | 视线只到对方胸口，报名字时省略姓 |
| 愧疚 | 心怀愧疚 | 把钱推过去时，手没有离开桌面 |
| 羡慕 | 他很羡慕 | 目光跟着对方的车钥匙走了一小段 |

## 三、B 组 · 处境受压（6 词）

**这股情绪从哪儿来**：环境、时间或他人的权力压过来，当事人无法脱身。
**通用切入口——看呼吸与手**：人受压时最先失控的是呼吸节奏和指头的小动作，表情反而是最后才变形的。写呼吸、写指头，比写眼睛有效。

| 情绪 | 不要这样写 | 改成这样 |
|---|---|---|
| 紧张 | 气氛很紧张 | 拇指反复摩擦食指侧面，鞋尖在地上点了两下 |
| 恐惧 | 恐惧笼罩着他 | 手指在门把上打滑，咽口水声压在环境声下 |
| 压抑 | 压抑的氛围 | 说话前先看了一眼门的方向 |
| 绝望 | 陷入绝望 | 手机屏幕暗下去，他没有再按亮 |
| 委屈 | 满腹委屈 | 嘴唇动了一下，最终没出声 |
| 愤怒 | 他愤怒地站起来 | 指节抵住桌面发白，呼吸变粗，椅子被顶退半尺 |

## 四、C 组 · 内在转折（6 词）

**这股情绪从哪儿来**：没人逼他，是自己心里转过了一个弯或没转过去。
**通用切入口——看停顿**：心理活动发生的那一下，身体会停半拍。找到那半拍停在哪里（手停在半空、话停在嘴边、视线停在一处），情绪就落地了。

| 情绪 | 不要这样写 | 改成这样 |
|---|---|---|
| 尴尬 | 场面有些尴尬 | 视线同时避开，一个人去拧桌上的水瓶盖 |
| 羞耻 | 羞耻感涌上来 | 耳根泛红，衣领被往上拉了拉 |
| 犹豫 | 犹豫不决 | 手抬到门铃前停住，指节悬空 |
| 心动 | 她心动了 | 视线在对方手上多停了半秒，随即移开 |
| 震惊 | 震惊不已 | 杯子没拿稳，水泼在桌沿 |
| 疯狂 | 近乎疯狂 | 笑到一半停住，眼睛还睁着 |

## 五、D 组 · 欲望与落空（6 词）

**这股情绪从哪儿来**：想要什么，或者失去了什么。
**通用切入口——看物件**：想要的东西会出现在画面里（在桌上、在他手里、在别人手里）；失去的东西会让那个位置空着。不要写他多想要，写那个东西在哪。

| 情绪 | 不要这样写 | 改成这样 |
|---|---|---|
| 期待 | 满怀期待地等着 | 门每响一次都抬头，手在膝上握了又松 |
| 希望 | 重燃希望 | 抬头，把窗推开一条缝 |
| 幸福 | 画面充满幸福感 | 两个人分一副耳机，线在中间绷成一道弧 |
| 悲伤 | 她显得很悲伤 | 手里的水端到一半停住，水面晃出一圈 |
| 平静 | 内心平静 | 呼吸均匀，手里的事没停 |
| 疲惫 | 看起来很疲惫 | 领口松着，眼睛对焦慢半拍 |

## 六、执行步骤

1. 写完段 4 正文，全文搜一遍：`孤独 紧张 幸福 愤怒 悲伤 温暖 温柔 压抑 绝望 委屈 感动 高级感 氛围感 电影感`——命中即改。
2. 判断这个词属于哪一组，直接用该组的切入口下手（距离 / 呼吸 / 停顿 / 物件）。
3. 改完自检：能在画面里看见、或在声音里听见吗？不能就换通道重来。
4. **一镜只承载一个情绪落点**。五个通道全塞进一镜，等于什么都没说。

## 七、四条反例

- `画面充满压抑的氛围` —— 没有落点，模型无从执行。
- `她看起来很失落` —— 心理判断，不是可拍摄的动作。
- `高级感的色调` —— 模糊审美词，应换成具体规格：`低饱和青灰，窗光作为唯一主光`。
- `他百感交集` —— 复合情绪没拆开。先决定这一镜最想让观众读到哪一种，其余全部删掉。
