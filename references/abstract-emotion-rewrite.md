# 主体系 · 抽象情绪改写表（质检第 17 条执行工具）

> 来源：飞书文档《AI 漫剧提示词知识体系》4.3 情绪氛围 80 条——**反向使用**。它列的是「不能直接写进正文」的词，本表给出改写路径。
> 规则：段 4 不得出现抽象情绪词，一律改写为 **光位 / 材质 / 动作 / 物件 / 声音** 五个通道之一。质检第 17 条即查此项。
> 定位：质检工具，不改五段结构；本表只提供改写路径，不新增槽位。

## 一、五通道改写法

| 通道 | 问自己 | 写法示例 |
|---|---|---|
| 光位 | 光怎么落在他身上 | `顶灯只照到半张脸，另一侧留在暗里` |
| 材质 | 什么表面正在变化 | `掌心的汗把纸角洇软` |
| 动作 | 身体哪个部位先动 | `喉结动了一下` |
| 物件 | 什么东西替情绪说话 | `被指节压出白痕的纸杯` |
| 声音 | 什么声音暴露状态 | `呼吸声压在环境声之下` |

| 疯狂 | 近乎疯狂 | 笑到一半停住，眼睛还睁着 |

## 三、使用方式

1. 写完 CLIP 正文，全文搜一遍「孤独 / 紧张 / 幸福 / 愤怒 / 悲伤 / 温暖 / 压抑 / 高级感 / 氛围感」，命中即改写。
2. 改写后必须可拍：能在画面里看见，或能在声音里听见；两者都没有就是没改写。
3. 一镜最多承载一个情绪落点，不要把五个通道全塞进一个镜头。

## 四、三条反例

- `画面充满压抑的氛围` —— 无落点，模型无法执行。
- `她看起来很失落` —— 心理描写，不是可拍摄的动作。
- `高级感的色调` —— 模糊审美词；应改成具体规格：`低饱和青灰，窗光作为唯一主光`。
