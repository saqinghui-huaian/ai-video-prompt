# 主体系 · 视频分镜规格书 · 结构规范与槽位字典

本文件服务于 `SKILL.md` 定义的**唯一核心基准**：源画布 https://app.tapnow.media/canvas/0e561120-5c2d-4bd8-821b-f5c532645ec5 的 30 秒 5 镜 `[STYLE LOCK]` 规格书。静态图片提示词只是辅助模式，见 `references/image-prompt-guide.md`，不是并列体系。

基准范例见 `references/golden-example.md`。本文定义每个槽位写什么、不写什么。

## 一、段 1 `[STYLE LOCK]` 场景风格锁

固定七个子槽，按顺序写，用逗号或编号分隔，不用完整散文：

| 子槽 | 内容 | 反例 |
|---|---|---|
| `era_place` | 年代 + 国家/地区 + 具体空间 + 内/外景 | 「一个商店」 |
| `look` | 写实电影质感 / 文艺片色调 / 画幅（21:9、2.39:1 变形宽银幕）/ 景深 | 「好看的电影感」 |
| `camera` | 镜头运动方式与焦段，全片统一（如全程手持摇晃 Handheld Camera with natural breathing motion） | 每镜换一种运镜 |
| `lighting` | 光源种类、位置、色温、落地效果（顶灯向下洒光 / 门外自然侧光 / 门口地面光斑） | 「光线柔和」 |
| `set_dressing` | 可辨识年代物件（CRT 收银终端、扫码枪、纸质价签、玻璃门冷藏柜、防滑瓷砖） | 「一些货架」 |
| `crowd` | 时间 + 人群 + 服装 + 行为，让空间有人气 | 「有人」 |
| `grade_physics` | 胶片质感 / 偏色 / 物理真实性 / 对白语言规则 | 省略对白规则 |

**对白语言规则必写**：`画外所有说话声均为清晰中文语句`。这是防止模型生成含糊人声或外语的关键约束。

**可选交叉核对**：写完风格锁后如需额外查漏，可按 `references/dimension-library.md` 的「跨体系交叉核对」表对照时间、主体、场景、风格四大类；其中「光源类型 / 光源位置 / 光质」「景别 / 拍摄角度 / 构图」「摄影机焦段 / 焦点」三组最易漏，漏了会导致模型自由发挥光位与机位。主体系的必做质检以本文第七节 15 项为准。

风格锁只描述**本场固定不变**的内容。会随镜头变化的东西一律移到 CLIP 正文。

## 二、段 2 `[参考图锚定]`

每张参考图用一行，格式：

```
{{Image N}} = <名称>：<提供什么>。<不提供什么 / 以何为准>。
```

三条纪律：

1. **写明边界**。角色图通常「仅提供面部与服装参考」，并注明「本场状态（眼镜、发型、衣着整齐度）以正文分镜状态为准」。
2. **场景图不锁机位**。固定句式：「提供空间结构、光位、年代质感——各镜机位由正文定义」。
3. 编号从 `Image 1` 连续，且与 `image_ids` 传入顺序一致。

参考图与正文冲突时，以正文为准——这一句要显式写出来。

## 三、段 3 `[空间与站位声明]`

三段式：

1. **空间锚点**：用方位词固定关键物件（「收银台在中后部」「出口在收银台左侧」「货架区在右侧与后侧」）。全片所有镜头的左右关系以此为准。
2. **角色动线**：写完整动作链，用 `→` 串联，覆盖从入场到出画（「货架前拿两瓶水→绕货架→队尾→收银台前付硬币→提袋向画面左侧出口走→走出店门→出门后向画面右前方走出画」）。
3. **跨镜状态延续**：写明容易被模型忽略的持续状态（「镜5门内：李默身后收银台方向仍有排队的学生队伍」）。

这一段是防跳轴的核心。宁可啰嗦，不可省略。

## 四、段 4 `[CLIP正文（N镜）]`

默认 5 镜 / 30 秒，每镜约 6 秒。每镜必须包含五个成分，**顺序固定**：

| 成分 | 写法 |
|---|---|
| 机位与运镜 | 「货架前的特写，手持镜头带轻微呼吸感」「高机位俯拍…中景」「相机后拉」 |
| 主体连续动作 | 一条动作链，含物理细节（「瓶中的水随抽取晃了一下」「瓶底轻碰台面两声」）；并发动作写「与走路同时完成」 |
| 前景虚焦 / 背景虚焦 | 明确写出虚焦处有什么，制造纵深 |
| 群演动作 | 至少一处与主线无关的次要动作，维持空间真实感 |
| 画外对白 | 清晰中文原句，台词处写「（嘴唇开合与声音同步）」 |

写作纪律：

- 主体用名字或代词，不重复描述长相、服装。
- 动作写「可拍摄的物理过程」，不写心理（「稍稍低下头，眼神回正」可以；「感到失落」不行）。
- 声音标记直接嵌进动作（「『滴』」「车铃轻响一声」），与段 5 对应。
- 末镜必须有收束：视线转移 / 低头 / 出画 / 声场变化。

## 五、段 5 `[BGM & 声音设计]`

- 第一行「底层环境」：贯穿全片的环境声，并写明声场转换（「镜5跨出门后转室外声场（开阔·自行车铃·黄昏风）」）。
- 之后每镜一行：`镜N：<音效清单>·<画外对白>·<环境声>`。
- 音效与段 4 中嵌入的声音标记**逐项对应**，不新增画面里没发生的声音。
- 标注对白语言（「清晰中文」）。

## 六、参数建议（正文之外）

按目标模型给：模型版本、时长、比例、分辨率（先草稿后终稿）、原生音频开关、参考图顺序、seed 登记。公开资料中的常见单次上限：Seedance 2.0 4–15s、Veo 3.1 4/6/8s、Kling 3.0 3–15s、Seedance 2.5 4–30s、Wan 3.0 2–30s；以平台当期参数为准。

## 七、质检清单（输出前逐项核对）

1. 五段齐全、顺序正确，风格锁段位于首段（`[STYLE LOCK]` 标签可带可不带，与黄金范例格式一致即可）。
2. 风格锁含画幅、景深、运镜、光位、年代物件、人气、对白语言规则。
3. 参考图编号连续，且写明「机位由正文定义」「状态以正文为准」。
4. 空间声明含方位锚点、完整动线、跨镜状态延续。
5. 镜数 × 单镜时长 = 总时长；时间码连续无重叠。
6. 每镜含机位、连续动作、前后景虚焦、群演、画外对白五项。
7. 相邻镜无跳轴、无运动方向反转。
8. 主体外观未在正文重复描述。
9. 所有对白为中文清晰原句，台词标注唇音同步。
10. 段 5 逐镜音效与段 4 声音标记一一对应。
11. 跨室内外写明声场转换。
12. 末镜有收束动作与落幅交代。
13. 无抽象情绪词、无「好看/高级感」类模糊表述。
14. 负面约束含：变形、多手指、面部崩坏、文字水印、多余人物。
15. 附模型参数与 seed 登记项。
