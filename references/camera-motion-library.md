# 主体系 · 运镜与镜头词库（查漏用）

> 来源：飞书文档《AI 漫剧提示词知识体系》第 3 章（镜头类型库 80 条 / 运镜模板 16 类 45 条 / 即梦 4.5 运镜 50 条 / 摄影手法 60 条），2026-11 清洗重写。
> 定位：`references/dimension-library.md` 运镜表的深水区补充。**只补词，不改结构**——五段结构、槽位定义、20 项质检一律以 `references/spec-guide.md` 为准，本文件不构成第二套体系。
> 清洗记录：原表 10 条 → 本文件 34 式；删除概念重复 5 对（主观 / 旋转 / 跟拍 / 低角度 / 镜中）；修正「秒/帧」单位错误 10 处；剔除「8K 高清」类无效参数 16 处。

## 一、取词四条纪律

1. **段 1 定体系，段 4 只在内变化**：`camera` 槽写全片统一运镜体系（全程手持 / 全程轨道 / 全程固定），段 4 每镜的运镜必须在体系内变化，不允许一镜手持、一镜航拍、一镜环绕。
2. **一镜一个主运镜**：复合运镜最多两段，且必须写清先后（`先缓慢推至面部，再定点跟摇`），不许并列三个。
3. **速度写「倍速 / 整镜用时」**，不写「秒/帧」——帧是画面单位，不是时间单位，写进去会被模型当噪声。
4. **运镜必须带主体锚点**：写「推到哪里、跟谁、绕谁」，不写光秃秃的「环绕镜头」。

## 二、基础运镜 34 式

| 运镜 | 英文 | 叙事用途 | 一句式写法 | 反例 |
|---|---|---|---|---|
| 固定 | static | 冷静观察、对话沉淀、压抑 | `定镜，中景，机位不动，人物在画面内完成动作` | 写定镜却让人物走出画面 |
| 推·慢 | slow push in | 情绪递进、注意力收拢 | `缓慢推进，从中景推到面部特写，整镜 4–6 秒匀速` | 只写「推镜头」不写推到哪 |
| 推·快 | crash zoom | 惊觉、发现、冲击 | `快速推进，0.3 秒完成，带轻微运动模糊` | 与慢推混用，节奏互相抵消 |
| 推·渐进 | progressive push | 悬念升级、压迫逼近 | `由慢到快推进，前三分之二匀速，后段加速` | 全程变速，画面抖成噪声 |
| 拉·缓 | slow pull back | 交代环境、孤独感 | `缓慢后拉，从特写拉到全景，露出身后空荡的走廊` | 拉到画外，无落点 |
| 拉·快 | snap pull out | 揭示全貌、反转 | `快速后拉，1 秒内从面部拉到全景` | 拉完画面里没有新信息 |
| 横移 | truck | 平行跟随、空间展示 | `水平横移，与人物同速，背景产生视差` | 移动方向与人物相反 |
| 斜移 | diagonal truck | 增强纵深 | `斜向移动，从前景斜穿到后景` | 速度与主体不匹配，主体忽远忽近 |
| 弧形移 | arc move | 展示主体与环境关系 | `沿弧线绕到主体右后方，主体保持在画面左侧` | 无圆心地「环绕」 |
| 跟·背后 | follow from behind | 代入、行进 | `背后跟拍，人物在画面中部，肩线随步伐起伏` | 跟拍时主体忽左忽右（跳轴） |
| 跟·侧 | side tracking | 速度感、平行叙事 | `侧面跟拍，与奔跑者同速，背景横向流动` | 背景静止（说明没真跟） |
| 跟·低机位 | low tracking | 力量感、地面细节 | `贴地跟拍，机位高约 20cm，带起地面尘土` | 低机位却拍成俯视 |
| 摇·左右 | pan | 依次呈现、空间扫描 | `从左向右摇，依次带过 A→B→C，摇速均匀` | 摇到空白处停留 |
| 摇·上下 | tilt | 高差展示、全身 | `自下而上摇，从鞋面摇到面部` | 一摇带两个主体 |
| 摇·环形 | orbit pan | 群像、对峙 | `360° 环形摇，绕中心人物一周，速度均匀` | 环绕时主体出画 |
| 升镜 | crane up | 揭示规模、升华 | `升镜，从脚部升到头顶以上，背景逐渐展开` | 升到与主体无关处 |
| 降镜 | crane down | 压迫、聚焦地面线索 | `降镜，从高空降到地面血迹特写` | 降速过快，观众晕 |
| 环绕 | orbit | 高光、仪式感 | `以主体为圆心环绕 180°，主体始终居中` | 圆心漂移 |
| 旋转 | roll / spin | 眩晕、失衡、梦境 | `镜头随人物倒地做 90° 侧滚` | 连续多镜旋转（滥用） |
| 变焦·入 | zoom in | 机位不动锁定细节 | `机位不动，焦距快速拉长，从全景压到胸前徽章` | 与推镜混用（推是移动机位） |
| 变焦·出 | zoom out | 揭示环境突变 | `机位不动，焦距缩短，从面部退到封闭房间` | 变焦出没带来新信息 |
| 手持 | handheld | 纪实、不安 | `手持，带自然呼吸式轻微晃动，幅度小于画面 3%` | 晃成地震 |
| 甩镜 | whip pan | 对峙、暴力切换 | `甩镜，从 A 的脸甩到 B 的脸，带 2–3 帧残影` | 甩完落点不清 |
| 俯冲 | dive | 降临、救援、压迫 | `俯冲，从云层视角冲向地面人物，由慢到快` | 无落点，冲到画外 |
| 穿越 | through-the-space | 空间连接、一镜到底 | `穿窗而入，从室外穿进室内，窗框擦过画面边缘` | 穿越处几何穿模 |
| 主观 POV | POV | 沉浸、代入 | `第一视角，视线高度约 1.6m，带轻微步伐起伏` | POV 里出现自己的脸 |
| 越肩 | over-the-shoulder | 对话、对峙关系 | `越肩拍，前景是 A 的肩与后脑虚焦，焦点在 B 的脸` | 机位压进肩内，画面被挡 |
| 反打 | shot / reverse | 对话衔接 | `反打，机位在 B 侧，A 在画面右侧，视线高度一致` | 反打跳轴 |
| 定格 | freeze | 强调瞬间 | `主体定格，背景保持运动，定格 1 秒后恢复` | 全画面冻结，失去对比 |
| 延时 | timelapse | 时间流逝 | `延时，云层快速流动，人物保持同一位置` | 人物也快放，变成闹剧 |
| 水下 | underwater | 失重、窒息 | `水下仰拍，气泡上浮，光线从水面折射` | 无水感，像隔着玻璃 |
| 航拍 | aerial | 规模、地理关系 | `航拍垂直俯拍，人物在画面中占比小于 1/20` | 高度不够，像摇臂 |
| 倒置 | inverted | 失衡、精神异常 | `画面旋转 180°，人物倒挂，重力感消失` | 无动机倒置 |
| 遮挡 / 窥视 | obscured | 悬疑、旁观 | `前景门缝遮挡，仅留约五分之一缝隙可见人物` | 遮挡过多，看不清主体 |

## 三、节奏三档写法

| 档位 | 写法模板 | 适用 | 注意 |
|---|---|---|---|
| 慢 | `缓慢推进，整镜 5–6 秒匀速完成` | 情绪铺垫、告别、凝视 | 不要叠加手持晃动 |
| 中 | `匀速推进，整镜 3 秒` | 常规叙事、对话推进 | 与动作起点对齐 |
| 快 | `快速推进，0.3–0.5 秒完成，带轻微运动模糊` | 惊觉、打断、冲击 | 一镜最多一次 |
| 渐进 | `前三分之二匀速、后段加速，整镜 4 秒` | 悬念收口 | 变化点要落在动作上 |

原文档写「速度 2 秒/帧」「0.8 秒/帧」——单位错误，已统一改为上述写法。

## 四、四类场景的镜头序列骨架

1. **战斗**：`侧跟（起势）→ 快推（击中瞬间）→ 环绕（对峙）→ 升镜或慢动作（收势）`。忌每镜换体系；忌连续三个快切。
2. **对话**：`定镜双人中景 → 越肩 A → 反打 B → 慢推至面部（情绪转折）`。忌对话用环绕、旋转、航拍。
3. **回忆**：`定镜特写 → 缓慢虚焦 → 叠化入闪回（暖调 + 颗粒）→ 变焦回现实面部`。忌闪回用快切，破坏时间层。
4. **探索**：`POV 前行 → 低机位跟 → 变焦锁定关键物 → 拉远揭示空间`。忌 POV 与第三人称无过渡混切。

## 五、与风格锁、参考图的衔接

- 段 1 `camera` 写**体系**（手持 / 轨道 / 固定），全片不变；段 4 写**本镜具体运镜**，只在体系内变化。
- 参考图只锚外观与空间结构，**不决定运镜**；冲突以正文为准（见 `references/reference-image-protocol.md`）。
- 同场次连续镜头保持同一侧轴线、同一焦段倾向，否则模型每镜重排房间。

## 六、六种失败模式

1. 每镜都「手持跟随」→ 五镜同质，剪辑没有节奏。
2. 运镜无主体锚点 → 模型自由旋转，人物在画面里漂。
3. 一镜塞三段运镜 → 动作链断裂，人物瞬移。
4. 运镜方向与动线相反（人向左跑、镜头向右摇）→ 跳轴。
5. 复杂运镜连续使用（旋转 / 穿越 / 鱼眼）→ 观众疲劳 + 几何崩坏。
6. 用风格名代替运镜（「新海诚式镜头」）→ 模型无法执行，等于没写。
