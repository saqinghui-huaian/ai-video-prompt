# 体系 B · 风格锁词库

从 `Creative Concept (1016)` 画布的视频节点 `[STYLE LOCK]` 段归纳。用法：按题材选一组「整体风格 + 色调 + 质感 + 运镜」，再补光位、陈设、人气、对白规则。**同一部片内跨场次只换色温与光位，不换画幅与运镜体系**。

## 一、两套对立色温（叙事论点，不是滤镜）

### 暖系 · 过去 / 县城 / 高中 / 生日宴

```
整体风格：2006年中国县城高中生生日聚会，暖到发腻的假热闹，真实电影实拍质感。
色调：暖金午后阳光（落地窗逆光）与吊灯筒灯暖黄顶光叠加，房间明亮通透；酒红绒椅、米白桌布、可乐深棕色玻璃杯反光；Fuji 400H 胶片色彩，暗部保留层次，细腻胶片颗粒。
质感：anamorphic 变形宽银幕镜头质感，浅景深，手持摄影·画面带明显摇晃的生活流、零摆拍感。
电影质感：手持摇晃贯穿，真实胶片颗粒，Live action not animation。
```

情绪曲线变体（写进风格锁，比写「氛围悲伤」有效）：
- `从狂欢顶点到死寂`
- `热闹顶点里藏着一个局`
- `热闹的顶点`

### 冷系 · 现在 / 大厂 / 面试间

```
①风格锁定：写实2020年代中国互联网大厂职场剧情片质感，冷峻、克制、权力落差下压住的紧绷安静；关键词：corporate interview room, overcast cold daylight, quiet realism, film grain。
②色调：低饱和冷灰系统一——落地窗阴天漫射冷白光，深黑胡桃木桌面与深炭黑地毯压底，浅灰墙面过渡。
③质感：胶片颗粒，浅景深，手持微呼吸；礼貌表皮下的送客判决 / 寒暄表皮下的审讯感。
```

情绪变体：`权力落差下压住的紧绷安静`、`礼貌表皮下的送客判决`、`寒暄表皮下的审讯感`。

## 二、摄影规格（全片锁定，不逐镜改）

| 项 | 常用写法 |
|---|---|
| 画幅 | `21:9 超宽银幕` / `变形宽银幕 anamorphic` / `2.39:1` |
| 景深 | `浅景深，背景虚化` |
| 运镜 | `全程手持摇晃镜头 Handheld Camera with natural breathing motion`；`手持微晃`；`极端手持、失稳构图、时不时虚焦` |
| 纪录片式 | `Handheld documentary-style cinematic short film, realistic. Anamorphic lens, shallow depth of field, subtle film grain, 文艺片质感` |
| 焦段 | `28mm 广角`（室内纵深）、`35mm`（群像定妆）、`85mm 长焦`（权力压缩）、`18mm FPV 超广角` |
| 胶片 | `Fuji 400H 色感`、`真实胶片颗粒`、`细腻胶片颗粒，暗部保留层次` |
| 真实性 | `人物运动物理真实`、`Live action not animation`、`真实电影实拍质感` |

## 三、光位模板

- 室内顶光：`天花板上圆形嵌入式暖黄顶灯从顶向下洒光，光线柔和偏暖亮`
- 门侧光：`大面积玻璃金属框推拉门透进自然侧光与街景绿植，门口一小片地面泛着门外的光`
- 混合光：`包间暖黄主光与落地窗冷天光混合，汤汁、奶油、碎瓷的高光做画面最亮层，人物肤色沉在暖调中段，暗部保留深棕分离`
- 职场冷光：`阴天漫射冷白天光铺满纵深端，低饱和办公室色盘`
- 逆光：`落地窗暖金逆光把人侧脸镀边`

## 五、声音规则

- 必写：`画外所有说话声均为清晰中文语句`
- 台词标注：`（嘴唇开合与声音同步）`
- 群演对白样例：`「哎，这个新出的，要不要试试」`、`「昨天那球绝了，你看到没」`、`「谢谢阿姨」`、`「三块钱。」`
- 声场转换：`室内闷混响转室外开阔`、`跨出门后转室外声场`
- 节拍写法（把剪辑节奏写进 prompt）：`节拍器式的文件磕桌开场·舒适区自供的中段·卡壳收尾的侧面抽离——handheld interrogation rhythm`

## 六、一致性工程（跨场次 / 跨年龄）

- 角色设定图：`Character sheet of <NAME>, an 18-year-old ...`
- 跨年龄：`CHARACTER SHEET — <NAME>, 32, ... Same person as the attached 18-year-old character sheet`
- 配角：`Prompt: A 2x2 character reference sheet of ...`
- 道具：`A three-view turnaround reference sheet of a single paper cone party hat (2006 small-town China style), product photography on a clean background`
