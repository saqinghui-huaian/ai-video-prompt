# 静态图 · 提示词查漏八步（辅助模式）

> 定位：**辅助模式（单张静态图）的选项库**，服务 `assets/image-prompt-template.md` 的骨架与 `references/image-prompt-guide.md` 的工作流。
> 骨架沿用主体系段 1 的七个槽位，所以不需要另记一套分类——**同一套标签，写视频时查七槽，写单张图时查八步**，只是把「主体」和「镜头」两项补细。
> 用法：八步是**查漏顺序**，不是书写顺序。书写顺序见模板；查漏时从第一步走到第八步，逐项确认「写了」或「有意留空」。

## 一、八步与七槽的对应关系

| 步 | 查什么 | 对应主体系槽位 | 漏了会发生什么 |
|---|---|---|---|
| 1 定点 | 什么年代、什么地区、什么时刻、室内还是室外 | `era_place` | 模型默认给「现代、无地域特征」的通用场景 |
| 2 定调 | 什么质感、什么色调、多大画幅、多浅景深 | `look` + `grade_physics` | 出来像渲染图，不像拍的 |
| 3 定光 | 光从哪个方向来、什么质地、落在哪儿最亮 | `lighting`（**最常漏**） | 模型自编平光，所有立体感消失 |
| 4 定景 | 环境长什么样、有什么陈设、有几个人 | `set_dressing` + `crowd` | 空间空荡，没有年代与生活痕迹 |
| 5 定主体 | 画面里是谁、长什么样、在做什么 | 由参考图或文字锚点承担 | 主体变成「一个男人」这类无名氏 |
| 6 定镜头 | 景别、角度、构图、焦段、焦点 | `camera` 的静态投影 | 景别与角度打架，或完全没定 |
| 7 动效 | 只有做视频时才查：运镜、节奏、转场 | 段 4 + 段 5 | 单张图不需要，多镜时才补 |
| 8 排除 | 不要出现什么 | 负面约束 | 手指、文字、水印类崩坏不设防 |

主体系的必做质检以 `references/spec-guide.md` 第七节为准；本表是单张图的补充，不替代它，也不是逐项填表格。

## 二、第一步 · 定点

| 项 | 可选值 |
|---|---|
| 年代 | 当代 / 近代 / 现代 / 古代 / 未来 / 架空 |
| 季节 | 春 / 夏 / 秋 / 冬；或「无季节特征」 |
| 时刻 | 拂晓 / 清晨 / 上午 / 正午 / 下午 / 黄昏 / 入夜 / 深夜 |
| 地区 | 具体到国家 + 城市层级（中国·县城 / 日本·郊区），不写「亚洲某地」 |
| 内外景 | 室内 / 室外 / 半室外（廊下、门厅、车厢） |

写「2012 年中国县城·秋·午后·室内」比写「一个教室」多给出的信息量，是模型能否一次出对的关键。

## 三、第二步 · 定调

### 画面门类

| 大类 | 常见分支 |
|---|---|
| 实拍向 | 文艺片 / 悬疑 / 科幻 / 恐怖 / 纪录 / 武侠 / 广告质感 |
| 动画向 | 二维手绘 / 三维渲染 / 粘土定格 / 剪纸定格 / 毛毡 |

### 色调

- 冷暖方向：偏暖 / 偏冷 / 中性
- 具体色名（写色名，不写「高级」）：冷蓝灰、暖金、青橙对撞、莫兰迪灰、钠灯橙 + 日光灯白
- 明暗结构：高光留给谁、暗部保留多少层次

### 画幅与景深

`21:9 超宽` / `2.39:1 变形宽银幕` / `16:9` / `4:5 竖构图`；`浅景深、背景化开` / `大景深、前后都实`

### 质感与真实感

`Fuji 400H 色感` / `Kodak Portra 颗粒` / `细腻胶片颗粒，暗部保留层次` / `Live action not animation` / `人物运动物理真实`

### 情绪基调（只定方向，不能当画面内容）

温馨 / 悬疑 / 宁静 / 孤寂 / 史诗 / 压抑 / 荒诞 / 冷峻 / 松弛

这九个词只用来**选方向**，直接写进提示词等于没写。落笔时必须转译成另外三步里的东西：第三步的光（`顶灯只照到半张脸`）、第五步的身体状态（`肩膀塌下去半寸`）、第四步的物件（`双人床只铺了一侧`）。转译路径见 `references/abstract-emotion-rewrite.md`。

## 四、第三步 · 定光（最常漏，必须写满四项）

| 项 | 可选值 |
|---|---|
| 光源性质 | 自然光 / 人工光 / 混合 |
| 光源方位 | 顺光 / 侧光 / 顶光 / 底光 / 逆光（背光） / 侧逆光 |
| 具体光源 | 落地窗天光、百叶窗条纹光、顶嵌筒灯、霓虹招牌、钠灯路灯、烛火、屏幕光、车灯、聚光灯、激光束 |
| 光质 | 硬光（边缘锐利、影子清楚） / 柔光（过渡长、无硬边） / 混合 |

**还要写落地效果**——光最终在画面里留下什么：`门口一小片地面泛着门外的光`、`镜片上一道细窄高光`、`桌面反光把下颌照亮`。只写「光线柔和」等于没写，模型会自己编。

## 五、第四步 · 定景

### 自然类

- 环境：山地 / 河谷 / 林区 / 荒漠 / 海岸 / 城市天际线 / 云层与星空
- 植被：密度、种类、季节状态（枯黄 / 新绿 / 落尽）

### 建筑类

| 项 | 写法 |
|---|---|
| 年代 | 与第一步一致，可写「九十年代砖混校舍」这类具体形制 |
| 状态 | 新建 / 在用 / 陈旧 / 破败 / 废弃 / 半拆 |
| 结构 | 层高、开间、门窗形制、走廊走向 |
| 内装 | 风格（中式 / 欧式 / 现代极简 / 未来感）+ 家具款式与摆位 |

### 天气

晴 / 阴 / 雨 / 雪 / 雾 / 沙尘；写强度（细雨 / 暴雨 / 初雪）

### 年代物件与人气

- 年代物件写到品类 + 状态：`老式 CRT 显示器，边角磨白`；不写「复古摆件」
- 人气：时段 + 人数 + 在做什么，`放学时分，三五个学生在货架间挑东西`

## 六、第五步 · 定主体

### 人物

| 层 | 写什么 |
|---|---|
| 基础 | 性别、年龄（写具体数字）、肤色与人种、国籍、职业 |
| 脸部 | 发型（长度 + 颜色 + 分缝）、眉毛与胡须、皮肤状态（肤色 / 疤痕 / 痘印 / 纹身 / 皱纹）、脸型、五官特征 |
| 身体 | 身高体型（写形容词而非数字更稳）、体态、特殊特征（义肢 / 旧伤 / 明显胎记） |
| 服装 | 款式、颜色、材质纹理、细节状态（袖口扣到腕、领口松着、裤脚沾泥） |
| 表情 | 只写能看见的肌肉状态：`笑到一半停住`、`下颌绷紧` |
| 气质 | 一个词，且要能指向身体状态：`拘谨` 比 `温润` 可执行 |
| 姿势 | 只写一个主动作 + 承重腿 + 手的位置 |

### 生物

物种 / 品种 / 体量 / 年龄 / 性别 / 体型；特征结构（犄角、翅膀、尾）；毛发（长度、颜色、状态）；姿势

### 物品

类型；形状、尺寸、颜色、材质；表面状态（磨损 / 污渍 / 划痕 / 反光）；风格取向（工业 / 赛博 / 科技感 / 极简 / 手作）

**主体必须具体到独一无二**：写「穿藏青风衣、圆框眼镜、四十上下」而不是「一个中年男人」。

## 七、第六步 · 定镜头

| 项 | 可选值 | 注意 |
|---|---|---|
| 景别 | 大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 | 与主体信息量匹配：全身看姿态，特写看肌理 |
| 角度 | 平视 / 俯视 / 仰视 / 斜角（荷兰角）/ 鸟瞰 / 贴地 | 角度本身表态度，别随手选 |
| 构图 | 居中 / 三分（左或右）/ 前景遮挡 / 对称 / 大留白 | 留白方向暗示人物朝向 |
| 焦段 | 14 / 24 / 28 / 35 / 50 / 85 / 135 / 200mm；超广角 / 广角 / 标准 / 中长 / 长焦 | 广角近身有张力，长焦压缩空间 |
| 焦点 | 对在哪儿（`焦点在眼睛`）、景深范围、虚化程度 | 不写就会全实或全虚 |
| 透视 | 平视无变形 / 近大远小夸张 / 压缩扁平 | 与焦段一致，别自相矛盾 |
| 机型 | 拍立得 / DV / ARRI ALEXA 35 / IMAX 胶片 / 手机直出 | 决定整片的成像口味 |

**四个项必须自洽**：`特写 + 俯拍大全景` 是矛盾组合；`85mm + 大留白 + 强透视` 也互相打架。

## 八、第七步 · 动效（只在做视频时查）

### 运镜

| 运镜 | 英文 | 适合什么情绪 |
|---|---|---|
| 推（慢 / 快 / 渐进） | push in | 注意力收拢、发现、悬念升级 |
| 拉（缓 / 快） | pull back | 交代环境、孤独、反转揭示 |
| 摇（左右 / 上下 / 环形） | pan / tilt | 依次呈现、空间扫描、群像 |
| 移（横 / 斜 / 弧） | dolly / truck | 平行跟随、纵深视差 |
| 跟（背后 / 侧 / 贴地） | tracking | 代入行进、速度感、地面细节 |
| 升降 | crane / jib | 揭示规模、压迫、收势 |
| 环绕 | orbit / arc | 高光、仪式感、对峙 |
| 旋转 | roll / spin | 失衡、眩晕、梦境 |
| 变焦（入 / 出） | zoom in / out | 机位不动锁细节、环境突变 |
| 手持 | handheld | 纪实、不安 |
| 固定 | static | 冷静、压抑、对话沉淀 |
| 航拍 | aerial | 规模、地理关系 |
| 甩镜 | whip pan | 对峙、暴力切换 |
| 俯冲 | dive | 降临、救援 |
| 穿越 | through-the-space | 空间连接、一镜到底 |
| 主观视角 | POV | 沉浸、代入 |
| 越肩 / 反打 | over-the-shoulder / shot-reverse | 对话与对峙关系 |
| 定格 / 延时 | freeze / timelapse | 强调瞬间、时间流逝 |
| 水下 | underwater | 失重、窒息 |
| 倒置 | inverted | 失衡、精神异常 |

每一式的具体写法、反例与节奏档位见 `references/camera-motion-library.md`（34 式，含「一镜一个主运镜」等四条取词纪律）。

### 节奏

慢动作 / 延时 / 常速；舒缓 / 急促。**写法用「倍速 / 整镜用时」**（`缓慢推进，整镜 5–6 秒匀速`），不写「秒/帧」——帧是画面单位，不是时间单位。

### 动作时序

- 先后链：`先……然后……`
- 并行：`……的同时……`（最多两个）
- 禁止：一句话里塞三个以上独立动作

### 转场

硬切 / 叠化 / 黑场 / 匹配剪辑 / 甩入

## 九、第八步 · 排除项

`变形、多手指、面部崩坏、肢体扭曲、文字、字幕、水印、logo、低画质、过曝`

英文对照：`deformed, extra fingers, distorted face, text, watermark, low quality, overexposed`

按平台是否支持负面提示词决定加不加，不强求。

## 十、最高频的三个漏项

1. **光的四项只写了一半**——写了「柔光」没写方位和落地效果。补法是回到第三步，把「从哪来、落在哪、最亮的是谁」三句话说完。
2. **主体停在标签层面**——写了「一个女孩」没写发型、服装状态、手在哪。补法是回到第五步，逐个层过一遍。
3. **镜头四项互相打架**——景别说特写、角度说俯拍全景。补法是回到第六步，四项一起念一遍，看能不能同时成立。
