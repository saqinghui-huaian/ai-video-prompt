## 体系归属与跨体系交叉核对

本文件是**体系 A（图片提示词）**的主维度库。体系 A 直接按下方四维选项取词，模板与工作流见 `assets/image-prompt-template.md`、`references/image-prompt-guide.md`。

**体系 B（视频分镜规格书）是独立体系**，有自己的五段结构与 15 项质检，不以本表为准。仅当体系 B 写完风格锁后想额外做一次维度查漏时，可**可选地**按下表交叉核对：

| 导图中的维度 | 体系 B 里对应的落点（可选核对） |
|---|---|
| 时间（年代 / 季节 / 时刻） | 段 1 `era_place`、`lighting` 中的自然光时段 |
| 主体（人物 / 生物 / 物品） | 段 2 参考图锚定 + 段 1 `crowd`；人物细项交给角色设定图，不在正文重复 |
| 场景（自然 / 建筑 / 天气） | 段 1 `set_dressing`、`lighting`；段 3 空间与站位声明 |
| 风格 · 画面风格 / 氛围 / 色调 | 段 1 `look`、`grade` |
| 风格 · 光源类型 / 位置 / 光质 | 段 1 `lighting`（**最常漏项**） |
| 风格 · 景别 / 拍摄角度 / 构图 | 段 4 每镜开头的机位描述；全片画幅在段 1 `look` |
| 风格 · 摄影机（机型 / 焦段 / 焦点 / 透视） | 段 1 `camera` 定全片运镜体系；段 4 每镜写具体焦段与焦点 |
| 视频扩展（运镜 / 节奏 / 时序 / 转场） | 段 4 每镜动作链 + 段 5 声音节奏 |

体系 B 的必做质检以 `references/spec-guide.md` 第七节为准；本表是补充，不是替代，也不是逐项填表。

## 二、主体

### 人物
- 基础：性别、年龄、肤色·人种、国籍、职业
- **脸部**：
  - 发型（头发长度、头发颜色）
  - 眉毛、胡子
  - 皮肤细节（肤色、疤痕·痘印·纹身、皱纹）
  - 脸型、五官
- **身体**：高矮、胖瘦、特殊特征（机械义肢、伤疤……）
- **服装**：风格、颜色、材质·纹理、细节
- 表情
- 气质
- 姿势 / 动作

### 生物
- 物种、品种、大小、年龄、性别、体型
- 特征·结构（翅膀、犄角……）
- 毛发（长度、颜色）
- 姿势 / 动作

### 物品
- 类型（手机 / 汽车 / 家具……）
- 形状、大小、颜色、材质
- 表面细节（磨损 / 污渍 / 划痕……）
- 风格（赛博朋克 / 工业风 / 科技感……）

## 三、场景

### 建筑

### 天气
晴天 / 阴天 / 雨天 / 雪天 / 沙尘暴……

## 四、风格

### 画面风格
- **写实**：文艺片 / 悬疑片 / 科幻片 / 恐怖片 / 纪录片 / 武侠片……
- **动画**：二维动画 / 三维动画 / 粘土动画 / 定格动画 / 毛毡动画……

### 氛围
温馨 / 悬疑 / 宁静 / 孤独 / 史诗 / 压抑 / 荒诞……

### 色调
- 冷 / 暖
- 具体色调颜色（冷蓝、暖黄、青橙对比、莫兰迪灰……）

### 光源
- 光源类型：自然光 / 人工光
- 光源位置：顺光 / 顶光 / 背光（逆光）/ 侧光 / 底光……
- 人工光源：聚光灯 / 激光 / 霓虹灯 / 烛光 / 屏幕光……
- 光质：柔光 / 硬光……

### 景别
大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写……

### 拍摄角度
仰视 / 俯视 / 平视 / 倾斜（荷兰角）……

### 构图
主体居中 / 主体靠左·右（三分法）/ 主体靠后（前景遮挡构图）/ 对称构图……

### 摄影机
- 品牌机型：拍立得 / DV / ARRI ALEXA 35 / IMAX 胶片……
- 焦段：超广角 / 广角 / 标准 / 中长焦 / 长焦（14mm / 24mm / 35mm / 50mm / 85mm / 135mm / 200mm……）
- 焦点：景深、虚化效果、对焦位置（"焦点在……上"）
- 透视关系

## 五、视频扩展维度

### 镜头运动（运镜）
| 运镜 | 英文 | 适用氛围 |
|---|---|---|
| 推 | push in | 聚焦情绪、紧张感 |
| 拉 | pull out | 揭示全貌、孤独感 |
| 摇 | pan / tilt | 跟随、展示空间 |
| 移 | dolly / truck | 沉浸式移动 |
| 跟 | tracking shot | 主体行进 |
| 升降 | crane / jib | 史诗开场收尾 |
| 环绕 | orbit / arc | 展示主体、高光时刻 |
| 手持 | handheld | 纪实、不安 |
| 固定 | static | 压抑、冷静观察 |
| 航拍 | aerial / drone | 大场景、上帝视角 |

### 速度与节奏
慢动作（slow motion）/ 延时（timelapse）/ 正常速度；舒缓 / 急促

### 动作时序写法
- "先……然后……"（先后链）
- "……的同时……"（并行，最多两个）
- 避免：一句里堆三个以上独立动作

### 转场（多镜头）
硬切 / 叠化 / 黑场 / 匹配剪辑 / 甩镜头（whip pan）

### 负面提示词（按平台支持情况附加）
变形、多手指、面部崩坏、肢体扭曲、文字、水印、logo、低画质、过度曝光
（deformed, extra fingers, distorted face, text, watermark, low quality, overexposed）
